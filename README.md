# twse-watch

台股每日追蹤小工具：自動抓取指定股票的收盤價、成交量、財報數據，計算營收年增率、毛利率、ROE、負債比率、量比、均線偏離等指標，並給出描述性的觀察重點。

> 這個工具只做資料整理與描述，**不是投資建議**，不保證資料完全正確或即時，請自行核對公開資訊並謹慎判斷。

## 資料來源

[FinMind API](https://finmindtrade.com)（公開資料，免費額度即可使用；若要提高每小時呼叫次數上限，可以免費註冊取得 token）。

## 安裝

```bash
pip install -r requirements.txt
```

## 設定

1. 打開 `twse_watch.py`，把 `WATCHLIST` 改成你要追蹤的股票代碼：

   ```python
   WATCHLIST = ["2330", "2317", "2454"]
   ```

2.（建議，非必要）到 [FinMind 註冊頁面](https://finmindtrade.com/analysis/#/account/login) 免費註冊、驗證信箱後取得 token，提高每小時呼叫次數上限：

   ```bash
   export FINMIND_TOKEN="你的token"
   ```

   **不要把 token 寫進程式碼或提交到 git 裡。**

## 執行

```bash
python3 twse_watch.py
```

每次執行會：
- 把結果印在終端機
- 附加記錄到本機的 `log.jsonl`
- 產生一份 `report.html` 網頁報表，並自動用瀏覽器打開（想關掉自動打開，把檔案開頭的 `OPEN_IN_BROWSER = True` 改成 `False`）

`log.jsonl`、`report.html` 都已被 `.gitignore` 排除，不會被提交。

可以用 cron（macOS/Linux）或工作排程器（Windows）設成每天自動跑一次，例如每個交易日下午 3 點：

```cron
0 15 * * 1-5 cd /path/to/twse-watch && /usr/bin/python3 twse_watch.py >> run.log 2>&1
```

## 這份報表在算什麼

- **財報面**：營收年增率、毛利率、營業利益率、淨利率、EPS、ROE、負債比率、現金流／淨利比
- **量能面**：量比（今日成交量 ÷ 5 日／20 日均量）
- **價格面**：股價相對 20 日／60 日均線的偏離、近一年高低點區間位置

每個指標後面附的文字（例如「營收年增強勁」「股價接近近一年高點」）都是**描述性的觀察**，不是買賣建議。

## 財報探測器

除了上面的一般觀察，程式還會額外跑一組常見的財報紅旗檢查（獨立標示在「財報探測器」區塊）：

- 應收帳款／存貨成長速度是否明顯超過營收成長
- 毛利率較上一期是否大幅波動
- 現金流／淨利比是否連續兩期偏低（獲利品質）
- 負債比率是否偏高、或較上一期快速上升

這些都是教科書上常見的會計分析角度，一樣**只是描述性的提示，不是投資建議**。

## 歷年財報深度分析頁面

每支股票除了 `report.html` 上的卡片，還會額外產生一個 `analysis_<代碼>.html`（例如 `analysis_2330.html`），點卡片上的「歷年財報深度分析 →」就會連過去，風格參考財報狗的健診頁面：

- **個股健診**：參考[財報狗公開說明](https://statementdog.com/blog/archives/14432)的健診邏輯重新計算
  - 地雷股健診（6 項）：自由現金流、營業現金流/淨利近 5 年表現、應收帳款與存貨週轉天數
  - 成長股健診（5 項）：月營收年增率連續 3 個月、毛利/營業利益/稅前淨利/稅後淨利年增率
  - 每項顯示 ✓ 通過 / ✗ 未通過 / — 資料不足，附上實際數字，評分制、不是投資建議
- **股價走勢**：近 2 年收盤價 + MA5／MA20／MA60 均線，下方附成交量柱狀圖
- **技術面指標**：RSI14、MACD(12,26,9)、KD(9)（常見簡化版公式，僅供參考，不是買賣訊號）
- **年度營收與淨利長條圖**（疊加營收年增率折線）
- **三率趨勢線圖**：毛利率／營業利益率／淨利率，近 8 年逐季
- **杜邦 ROE 拆解**：ROE = 淨利率 × 總資產週轉率 × 權益乘數（簡化版，用期末數字而非平均值）
- **本期 vs 去年同期對比表**

圖表用 [Chart.js](https://www.chartjs.org/)（CDN 載入，需要網路），一樣只是資料整理與描述，不構成投資建議。
